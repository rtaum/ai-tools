# AI Tools

A collection of agent skill sets for imitating a cross-functional software team.

The repository is organized by role. Each folder contains instructions, skills, and tool configuration for a specific type of teammate:

- `business analyst` — analysis, modeling, documentation, and diagram support.
- `team-lead` — task breakdown, architecture, and review guidance.
- `dotnet developer` — .NET and ASP.NET Core backend work.
- `go-developer` — Go backend and cloud service work.
- `ui developer` — React, TypeScript, browser UI, and accessibility work.
- `qa` — validation, test planning, and release confidence.
- `devops` — cloud, infrastructure, delivery, and operational safety.

## Goal

The goal is to collect practical AI skills and role prompts that can work together like a small cross-platform product team, or help one person simulate that workflow when needed.

## Usage

Use the folder that matches the role you want the agent to play. Keep role instructions small, direct, and task-focused. Add new skills only when they provide real value for that role.
